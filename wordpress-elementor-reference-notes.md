# Official Implementation References

## Draft preview and static front-page changeover

WordPress documents the preview workflow for saved page changes and supports desktop, tablet, mobile, and new-tab preview options. Draft pages can therefore be built and reviewed without being published. [WordPress Preview documentation](https://wordpress.org/documentation/article/how-to-use-the-preview-function/)

WordPress Reading Settings control which static page is used as the front page. The final home-page changeover should occur only after the new page is approved. [WordPress Reading Settings](https://wordpress.org/documentation/article/settings-reading-screen/)

## Plugin installation and maintenance

WordPress documents the dashboard workflow as **Plugins → Add New → search → Install Now → Activate**, and recommends a current backup before plugin updates. [WordPress Plugin Management](https://wordpress.org/documentation/article/manage-plugins/)

## Elementor capabilities and requirements

Elementor’s WordPress.org listing documents installation through the built-in Plugin installer, then creation through **Pages → Add New → Edit with Elementor**. It describes Elementor Pro features relevant to this project, including Theme Builder, custom CSS/code, dynamic content, Loop Grid, forms, and motion effects. [Elementor plugin listing](https://wordpress.org/plugins/elementor/)

Elementor documentation states that Theme Builder controls site-part templates and display conditions. Global font/color settings are managed centrally, and responsive editing provides device-specific controls and configurable breakpoints. [Theme Builder](https://elementor.com/help/the-elementor-theme-builder/) · [Global fonts](https://elementor.com/help/view-and-edit-global-fonts/) · [Global colors](https://elementor.com/help/view-and-edit-global-colors/) · [Responsive editing](https://elementor.com/help/mobile-editing/)
